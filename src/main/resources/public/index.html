🌱 Zero Waste Surplus Marketplace

Good edible food shouldn't become garbage.

The Problem: Bakeries, restaurants, and grocery shops bin fresh, edible food at closing time while everyday people pay full price elsewhere. This wastes food, money, and carbon emissions.

The Solution: A hyper-local marketplace where sellers list near-expiry surplus food, discounts rise automatically as closing approaches, customers reserve bites in evening pickup slots, and live impact is tracked.

About SaveBite

SaveBite is an architectural demonstration of a production-style surplus-food marketplace built in Java 17 and Javalin. It proves that software design patterns are not academic curiosities or whiteboard exercises—they solve tangible, high-impact business problems.

Technology Stack

  • Java 17 & Javalin 6: Lightweight, unopinionated web framework keeping patterns visible without heavy annotation magic.
  • Security & JWT: JJWT 0.12.x, HMAC-SHA256 signing, BCrypt hashing, HttpOnly SameSite=Strict cookies with token rotation.
  • Persistence: Embedded H2 database in file mode via plain JDBC behind Repository interfaces.
  • Live SSE Events: Server-Sent Events delivering millisecond pattern execution events to the browser.
  • Frontend: Pure vanilla ES Modules and CSS variables—zero build steps, instant browser refresh.

The 23 Design Patterns Distribution

Every single pattern lives in its own dedicated package under com.savebite.patterns with one class per file, annotated with @DesignPattern and synced with patterns.json.
